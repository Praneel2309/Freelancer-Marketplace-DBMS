# Freelancer Marketplace Database System

## Overview

A PostgreSQL database designed for a freelancer marketplace platform where:

- Freelancers showcase skills and portfolios
- Clients post projects
- Freelancers place bids
- Contracts and milestones are managed
- Payments, reviews, and disputes are tracked

---

## Features

- 16 normalized relations
- BCNF normalization
- Realistic dataset
- Advanced SQL analytics
- Freelancer, Client and Admin dashboards
